1. Executive Summary

Project 12 represents an ultra-high-fidelity, zero-dependency browser-based combat vehicle simulation and 3D CAD modeling suite. Built on a 6-DOF Rigidbody physics paradigm, the software faithfully replicates the Boeing AH-64E Apache Guardian attack helicopter operating over the mountainous terrain of the Kashmir Line of Control (LOC) around Forward Operating Base (FOB) Uri.

The vehicle replaces mechanical rotor physics with an advanced anti-gravity propulsion core capable of delivering continuous vertical thrust counteracting gravity, dynamic aerodynamic drag damping, and automatic center-of-mass balancing against asymmetrical weapon stores.

Zero-Dependency Engineering Mandate: All 3D vector calculations, matrix transformations, PID anti-windup clamping, cubic Hermite spline interpolation, 90-degree conical radar sweep dot products, and procedural Web Audio threat tone synthesis are implemented natively in pure code with zero third-party plugins.
